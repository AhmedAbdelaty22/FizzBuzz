# FizzBuzz

A small Java console program. You enter a number, and it tells you whether that number is divisible by 3, by 5, or by both.

## How it works

| The number is divisible by | Output |
|---|---|
| 3 and 5 | `FizzBuzz` |
| 5 only | `Fizz` |
| 3 only | `Buzz` |
| Neither | `Your Number is : <number>` |

## Example

```
Please Enter a Number : 15
FizzBuzz
```

## Requirements

- Java 25 or newer. The program is a compact source file (`void main()` with no class around it) and uses the `IO` class, which became standard in Java 25.

## How to run

**IntelliJ IDEA:** open the project folder and run `src/Main.java`.

**Terminal:** from the project folder, run:

```bash
java src/Main.java
```
